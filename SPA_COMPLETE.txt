💡 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────┐
│                        Traditional Page Load                            │
├─────────────────────────────────────────────────────────────────────────┤
│ Click Link                                                              │
│   ↓                                                                    │
│ Full page reload (1200-1500ms)                                         │
│   ↓                                                                    │
│ 326 KB of data transferred                                            │
│   ↓                                                                    │
│ Page flickers/blinks                                                  │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                        SPA Navigation (NEW!)                            │
├─────────────────────────────────────────────────────────────────────────┤
│ Click Link                                                              │
│   ↓                                                                    │
│ JavaScript intercepts (spa-navigator.js)                              │
│   ↓                                                                    │
│ AJAX request with X-SPA-Request header                                │
│   ↓                                                                    │
│ Smooth fade-out (300ms)                                               │
│   ↓                                                                    │
│ Server returns content only (50 KB)                                   │
│   ↓                                                                    │
│ Smooth fade-in (300ms)                                                │
│   ↓                                                                    │
│ URL changes via pushState                                             │
│   ↓                                                                    │
│ Alpine components reinitialize                                        │
│   ↓                                                                    │
│ Ready for next click (200-400ms total) ✨                             │
└─────────────────────────────────────────────────────────────────────────┘
